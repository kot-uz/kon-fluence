# Документация (kon-fluence)

Приложение документации: дерево страниц,
редактор на TipTap, вложения, черновики, разрешение конфликтов версий.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3010
npm run build    # сборка в ./build
npm run preview  # просмотр собранной версии
npm run lint
npm run typecheck # проверка типов TypeScript
```

По умолчанию данные хранятся на устройстве (режим `local`): они лежат в IndexedDB браузера, бекенд не нужен.
При первом открытии пространство наполняется демо-страницами.

## Структура

```
src/
  main.tsx                  точка входа
  i18n.ts                   инициализация i18next (неймспейс translations)
  styles/app-base.css       базовые стили, корень 10px под шкалы Tailwind
  app/
    docs/                   ← перенесённый модуль документации
      adapters/             единственное место связи с приложением
      types.ts              доменные типы модуля (страница, дерево, вложение)
      api/ components/ hooks/ local/ utils/
    App.tsx                 провайдеры и роуты
    layout/AppHeader.tsx    шапка: язык, тема, автор правок
    main/spaces/            список пространств (главная страница)
    services/docs/          createApi, в который модуль инжектит эндпоинты
        shared-components/      Loading, PageSimple, AppMessage
    store/ helpers/ auth/ theme/ translations/
```

## Маршруты

| Путь                                | Страница                                              |
| ----------------------------------- | ----------------------------------------------------- |
| `/`                                 | список пространств                                    |
| `/docs/space/:spaceId`              | документация пространства (откроется первая страница) |
| `/docs/space/:spaceId/:pageId`      | просмотр страницы                                     |
| `/docs/space/:spaceId/:pageId/edit` | редактирование страницы                               |

## Пространства

Пространства самостоятельные: список и страницы хранятся вместе — в IndexedDB (режим `local`)
или в бекенде (режим `cloud`). Список приходит из `GET /docs/Spaces`. Создание, переименование и
удаление — на главной странице. Удаление пространства удаляет и его страницы с вложениями.

Полностью очистить локальные данные можно кнопкой «Сбросить демо-данные» в диалоге
автора правок (иконка пользователя в шапке).

## Переключение на реальный бекенд

```dotenv
REACT_APP_API_URL=https://api.example.com
```

Режим хранения (`local` / `cloud`) выбирается в рантайме и хранится в `localStorage['docs-storage-mode']`.
Если `REACT_APP_API_URL` пустой, облачный режим скрыт.

Приложение будет обращаться к `/docs/Spaces/...`, `/docs/Pages/...`, `/docs/Attachments/...`
(контракт описан в `src/app/docs/local/handlers.ts`). Токен берётся из `localStorage`,
ключ `jwt_access_token`. Своей авторизации в приложении нет.

Переменные используют префикс `REACT_APP_`, хотя сборщик — Vite: подстановку
`process.env.REACT_APP_*` делает `define` в `vite.config.ts`.

## Автор правок

Бекенда авторизации нет, поэтому имя автора задаётся локально (иконка пользователя
в шапке) и хранится в `localStorage`. Оно подставляется в «Создал(а)» и «Обновлено».
